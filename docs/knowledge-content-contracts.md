2026-10-07；当前字段证据 server/item-schema.mjs、server/storage.mjs、src/types.ts；本节区分现已校验的旧结构与逐步引入的完整内容规则。知识点不是“六道词汇题的容器”。保存词条、补活用、补义项不要求生成题，专名/纯片假名允许零题。

## 共通身份与内容

聚合根沿用 item ID/owner/deck，不生成替代学习身份；复习排程引用该 ID，题目通过 knowledgeIds 多对多引用。正文生成时间为 input_at；source 保存真实原句、教材定位、对话摘要和可信度，不伪装官方出处。所有例句/图片均需来源与不确定性标记。语言文本、注音和读音分别保存；不在可作答内容中插入答案提示或假名括号。localizations 是解释语言，不改原日语。

硬校验关注字段类型、枚举、长度上限、引用 owner、ID冲突和数组结构；内容审查关注词义、读音、接续、事实、语体、干扰项可争辩性。长度满足、汉字表面匹配或中文译义相近，都不能证明知识正确。既有不完整知识点可渐进补充，不因新版可选结构阻断旧记录。

## 单词

|内容|规则与适用条件|错误或审查点|
|---|---|---|
|original / base_form|original 保存辞书形/标准表记；base_form 仅在与 original 不同时保存|不能把活用形当辞书形；整短语按中心词判断|
|reading / ruby_terms / annotations|全词假名；文本注音对应准确字面与上下文；专名可多读音，标可靠来源|同汉字不同义音、专名猜读、分词surface拼不回正文均需纠正|
|meaning_ja / meanings / sense|日文简明定义；义项拟采用稳定senseId，每个义项有适用对象/例句/读音/来源；旧meaning_ja/meaning_zh先保留主释义|sense结构尚未替代旧存储，不把多个不同义项压成一个强制同义替换|
|part_of_speech|精确名詞/動詞/形容詞/副詞等；整短语可为名詞句、動詞句|“语句/词语”不能代替语法词性；サ変名詞与动词用法区分|
|inflection_class / conjugations|动词/形容词按 godan/ichidan/suru/kuru/i_adjective/na_adjective；kind、form、reading；不规则读音显式提供|活用表不是机械换字；来ない=こない；名词不强造动词活用|
|examples|自然场景日语 + 对应中文；至少两个适用例句是当前普通词汇规则；注明对应sense|“课本学了X”是来源叙述，不是可评分语境；必须验证搭配和主体|
|patterns / points|搭配、助词、惯用结构及使用限制，配对例句；技能与具体知识分开|不能用几条泛泛考试建议代替真实使用限制|
|comparisons|近义词/易混词/日常说法；比较意义范围、对象、强度、语体、接续，不只中文意思|不可把同样正确的变体用作错误干扰项|
|register|written/spoken/both/formal；场合、礼貌、语域和exam_tip|口语不等于“读快”；需考察省略、缩约、终助词、立场和互动关系|
|core_memory|少量考场召回线索，强调区分依据，不复制全文|不能替代解释或编造绝对规则|
|images|记忆图可选；owner/资源ID/来源/说明；独立于题目答案|图像只是辅助，避免不相关视觉暗示，来源/许可不可缺|

题目关联可标 target/prerequisite/contrast 并指向senseId（新契约）；旧 itemId仍可读。詞形、义项或例句修订不修改历史题目冻结答案。

## 语法

|内容|规则与适用条件|错误或审查点|
|---|---|---|
|original / meaning|规范形式与中文/日文含义；区分多个用法|不可仅写“大概意思”后统一接续|
|patterns|接续形式、前后成分、词性/时态限制、自然例句和译文|名词/动词辞书形/た形/否定形不能混成一个泛化公式|
|points|语义、主语、意志性、时间先后、评价、句末形式等约束|成立接续不保证语义成立；规则例外需标说明|
|register|口语、书面、郑重/礼貌与场合限制，日常替代表达|“正式=难词”“口语=快读”均不是有效规则|
|comparisons|近似表达逐维度比较：接续、立场、事实/推测、强弱、上下句关系|只写中文近义无法支撑排除选项|
|examples|每条接续/用法有自然例句及译文，最好有最小差异对照|不强造不自然例句来凑类型；错误例需明确标记|
|core_memory / explanation|短召回与完整证据解释分开，说明为什么成立、何时不成立|不能只重复“选正确接续”作为解析|

语法的三种题目针对形式判断、句子组成、篇章衔接，均可关联同一知识点；并非一个语法条目必须有三题。句子组成还可能关联多个句法知识点；篇章语法同时关联接续词/指示词/时态/视点。

## 示例与实施边界

“規制”：サ変名詞，辞书定义“规则/法律下限制活动”；“交通を規制する”自然搭配；“塩を規制する”不自然，应“控える”。无可靠汉字读音不出漢字読み；纯片假名“チェック”不强出漢字読み/表記；专名不把另一个有效读音判错。

“〜にほかならない”：说明断定理由/本质；知识点保存其接续、语体、对比与例句。形式判断考空格语义接续；句子组成考“に＋ほか＋ならない”相邻关系；篇章语法考其总结立场是否与前文一致。
