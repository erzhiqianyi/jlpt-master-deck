## 2. 五题共用的作答规则

### 写与说分开设目标

- **口语表达**：准备30—60秒，只记3—5个关键词；正式表达约2分钟，建议1分45秒—2分15秒。准备、示范播放与额外追问不计入表达时间。不要求为了凑时长重复内容，也不能为赶时间牺牲清晰度。
- **完整写作**：400—500字，顺序为「立场→理由及例子→回应另一面→总结」。第1、3、4、5张图明确要求400—500字；第2张图没有显示字数，本站为它增加同样的写作档，不能标成原题要求。
- **写作朗读**：如朗读整篇长文，记录为朗读。独立表达要重新压缩成自己的关键词，再录一次，记录为表达。
- **语体**：初练用です・ます体；进阶写作可切换だ・である体，但同篇统一。范文默认使用です・ます体。
- **立场**：先说明主要选择，再补充条件。保留「原题二选一」模式；「有条件支持／折中提案」作为明确标注的扩展模式。不能只说“两边都好”而没有自己的判断。

### 每个主题的三种任务

1. **直接表达**：只显示场景与问题；自己提出立场、一个理由、一个例子，最后总结。
2. **赞同补充**：播放或阅读一位同学的观点；先赞同，再增加一个对方没有说过的理由或具体例。
3. **委婉反对**：播放或阅读一位同学的观点；先准确承接，再说明分歧、理由和自己的建议。

每题准备A、B两位虚构同学的意见，支持者选择A或B后都能练「赞同」，反对者也都能找到对应的回应对象。反对任务中的角色立场只服务表达训练，不记录为学习者本人的信念。

### 范文与shadowing

每题现有两种立场的短口语示范和一篇长文示范。现有短示范保留为局部句型与shadowing材料，不是完整2分钟答案。短口语每一行对应一个意义片段，括号外的角色／功能标签不读出。完整2分钟示范在制作音频前按下方结构扩写，结合长文的理由与例子改成自然口语；实际时长必须录音后测量，不从字符数推定已达标。

### 2分钟文章组织

| 段落 | 参考用时 | 要说什么 |
| --- | --- | --- |
| 立场／回应 | 20秒 | 明确选择；对话题先承接对方 |
| 理由 | 30秒 | 解释最重视的一点，避免只是重复立场 |
| 具体例 | 35秒 | 一个生活场景及其影响 |
| 另一面与取舍 | 20秒 | 承认另一种意见的合理之处，再说明自己的判断 |
| 总结 | 15秒 | 重申选择或提出建议，不再引入新论点 |

五题分别这样展开：不死之药补充一个明确标为假设的人生场景；储蓄与消费解释具体用途和另一种选择的价值；克隆题说明判断条件与出生者权益的例子；手机题比较两种使用行为并提出边界；居住题按两个生活标准比较并回应一项不便。用相关内容展开，不靠添加无关理由或拉长停顿凑时间。

录音界面显示「目标 2:00」和已录时长；1:40提示准备总结，2:00提示收尾，允许说完当前句子。3分钟仅为技术上限，不显示为目标。时长偏离只提供组织建议，不直接判错。

练习顺序：**首次独立表达→回听自查→选一份短示范→逐句跟读→连续shadowing→隐藏范文再次表达**。第一次不显示完整范文；可以主动点开，练习记录记下提示条件。

shadowing练节奏时保留选定示范原话；返回自由表达时允许改变理由、立场和措辞。不得用自由表达与范文的逐字相似度评价观点质量。

## 3. 题目一：不死之药

### 题面与边界

**もし「絶対に死なない薬」があったら、あなたは飲みますか。**

场景：

> 授業で、命と時間について話し合っています。「飲むと絶対に死ななくなる薬がある」と仮定して、自分ならどうするかを考えてください。

题设只保证「不会死亡」，没有说明不老、永远健康、价格、他人是否能服用或能否撤销效果。需要这些条件时，学习者应明确说「〜と仮定すると」「もし〜なら」。不能把“会死于某事”写成服药后的结果而违背核心假设。

主任务：选择喝或不喝；说明一个最重视的理由，用一个假设生活场景解释；回应相反立场的一个优点。

### 对话任务

- **A・佐藤さん**：私は飲みたいです。時間をかけて、いろいろなことに挑戦できると思うからです。
- **B・林さん**：私は飲みたくありません。終わりのない人生をどう生きるか、想像できないからです。
- **直接表达**：飲むか飲まないかを決め、その選択で自分の生活がどう変わるか説明してください。
- **赞同补充**：AかBの意見に賛成し、その人がまだ挙げていない理由を一つ加えてください。
- **委婉反对**：AかBの気持ちを受け止めた上で、違う考えとその理由を述べてください。

提纲提示：選択 → 大切にしたいこと → 想像した場面 → 反対意見への返答 → 結論。

表达工具：もし〜としたら／〜かもしれません／必ずしも〜とは限りません／〜という点はわかりますが。

### 短口语示范与切分

**M1-A：赞同“喝”并补充持续学习的理由**

1. 私も佐藤さんの意見に賛成です。
2. 私なら、その薬を飲んでみたいです。
3. なぜかというと、学びたいことがたくさんあるからです。
4. 例えば、一つの仕事を経験したあとで、別の分野を長く勉強したいです。
5. もちろん、健康に過ごせるかどうかはわかりません。それでも、私は長い時間を得られることに魅力を感じます。

**M1-B：回应“喝”，表达“不喝”**

1. 佐藤さんの意見もわかりますが、私は飲みたくありません。
2. 死なないことが、必ずしも幸せにつながるとは限らないと思うからです。
3. 例えば、自分だけが生き続けるとしたら、大切な人との別れを何度も経験するかもしれません。
4. 私は、時間の長さより、今の生活を大切にしたいです。

练习焦点：M1-B第2片段的「必ずしも〜とは限らない」与第3片段的条件句；先分句，再连成一段。第二次表达改用自己的一个理由，避免照搬“离别”。

### 400—500字写作示范：不喝（453字）

<!-- essay:opinion-immortality -->
私は、絶対に死なない薬があっても、飲まないと思います。人生で大切なのは、時間の長さだけではなく、誰とどのように過ごすかだと考えるからです。

確かに、死ななければ、いろいろな仕事に挑戦したり、長い時間をかけて世界を旅したりできるかもしれません。学びたいことが多い私にとって、その点は魅力的です。しかし、死なないことと、いつまでも健康で楽しく暮らせることは同じではありません。薬の効果が死なないことだけなら、私は安心して選べません。

例えば、自分だけがこの薬を飲むと仮定すると、家族や友人を見送ったあとも、生き続けることになります。新しい出会いがあるとしても、大切な人との別れを何度も経験する生活を、私は望みません。また、時間が無限にあると思うと、今やりたいことを後回しにしてしまう可能性もあります。

もちろん、長く生きたいという気持ちを否定するつもりはありません。それでも、私は限りのある時間の中で、自分にとって大切なことを選びたいです。したがって、薬を飲むより、今の人間関係や日々の経験を大切にしたいと思います。
<!-- /essay -->

反向长文提纲：喝 → 长期学习的价值 → 假设中的人生计划 → 承认健康等信息未知 → 说明为何仍倾向选择喝。

追问：**薬を飲んでも若いままでいられるとは限らないとしたら、考えは変わりますか。**

专项自查：是否区分“不死”与“不老／健康”；是否将设想标为设想；理由是否解释自己的选择，而非断言所有人都一样。

## 4. 题目二：储蓄与消费

### 题面与边界

**将来のために貯金することと、今の生活を楽しむためにお金を使うことでは、どちらを優先したいですか。**

场景：

> 友人とお金の使い方について話しています。生活に必要なお金を支払ったあと、残ったお金をどう使いたいか、自分の考えを述べてください。

「支付必要生活开支后」是本站为缩小争论范围增加的条件；原图是“尽量不花钱、为将来储蓄”和“积极花钱享受人生”的比较。讨论个人价值取舍，不要求透露真实收入、资产或提供具体投资选择。

主任务：选一个优先方向，说明理由，举出一种具体用途，并解释另一方向为何仍有价值。

### 对话任务

- **A・田中さん**：私は貯金を優先したいです。将来、予想していなかった出費があっても、落ち着いて対応できると思うからです。
- **B・王さん**：私は経験のためにお金を使いたいです。今しかできないこともあると思うからです。
- **直接表达**：どちらを優先するか決め、具体的な使い道や目的を一つ挙げてください。
- **赞同补充**：AかBに賛成し、「安心できる」「今しかできない」以外の理由や具体例を加えてください。
- **委婉反对**：AかBの良い点を認めた上で、自分がもう一方を優先する理由を述べてください。

提纲提示：優先する方 → その目的 → 具体的な使い道 → もう一方への配慮 → 自分の方針。

表达工具：〜よりも〜を優先したいです／〜ために／〜一方で／〜範囲で。

### 短口语示范与切分

**M2-A：赞同储蓄，补充未来选择的理由**

1. 私も田中さんの意見に賛成です。
2. 貯金があれば、将来の選択肢を増やせると思います。
3. 例えば、別の分野を学びたくなったとき、勉強のための時間を取りやすくなります。
4. もちろん、今の楽しみを全部我慢する必要はありません。
5. 私は使う目的を決めながら、まず貯金を優先したいです。

**M2-B：回应储蓄，选择有目的的消费**

1. 田中さんの意見もわかりますが、私は経験のためにお金を使うことを優先したいです。
2. なぜかというと、人と一緒に過ごせる機会は、あとから取り戻せないこともあるからです。
3. 例えば、友人と旅行することで、大切な思い出を作れると思います。
4. 必要なお金は残しながら、自分にとって意味のある経験を選びたいです。

练习焦点：M2-B第2片段的理由长句；按「人と一緒に過ごせる機会は／あとから取り戻せないことも／あるからです」做辅助停顿，正式朗读保持自然。重说时替换“旅行”为自己的用途。

### 400—500字写作示范：有目的地消费（455字）

<!-- essay:opinion-saving-spending -->
私は、生活に必要なお金を確保した上で、今の経験のためにお金を使うことを優先したいです。お金は持っているだけでなく、自分の生活を豊かにするために使うものだと考えるからです。

例えば、友人と旅行に行けば、普段とは違う景色を見たり、ゆっくり話したりできます。同じ場所にはあとから行けても、全員の予定が合う機会がまた来るとは限りません。また、興味のある講座を受ければ、新しい知識を得るだけでなく、自分が何をしたいのかを考えるきっかけにもなります。

もちろん、将来のために貯金することも大切です。予想していなかった出費があったとき、お金が残っていなければ困るでしょう。そのため、私は何でも好きなだけ買うことに賛成しているわけではありません。買う前に、自分にとって本当に必要か、あとでも満足できそうかを考えたいです。

貯金と消費のどちらかを完全になくす必要はありません。私なら、将来への備えを残しつつ、人との時間や学びにつながる経験にお金を使います。金額の大きさよりも、使った目的を自分で説明できることを大切にしたいと思います。
<!-- /essay -->

反向长文提纲：储蓄优先 → 安心与未来选择 → 学习／搬家等假设用途 → 承认当下体验的价值 → 保留适度享受的空间。

追问：**「今しかできない経験」かどうかを、どうやって判断しますか。**

专项自查：是否有明确优先顺序；是否把“积极消费”误写成“无计划花光”；例子是否和本人提出的目的相连。

## 5. 题目三：克隆人

### 题面与边界

**クローン技術を使って人を誕生させることに、賛成ですか、反対ですか。**

场景：

> 授業で、科学技術と人の権利について話し合っています。ここでは、研究用の細胞を作ることではなく、クローン技術で人を誕生させることを議論します。

本题讨论人类生殖性克隆，不用细胞研究、器官移植等不同对象偷换问题。条件赞成题可以假设未来满足安全与权益条件，但必须说清这是设想，不能暗示现实已经成熟可行。

教材示例中的“完全一样的人”“本物／分身”等论证不能直接作为科学事实。遗传上的复制不等于完整个体各方面都一样；题面不预设人格复制，也不把出生者写成价值较低的人。背景编辑依据：[NHGRI Cloning Fact Sheet](https://www.genome.gov/about-genomics/fact-sheets/Cloning-Fact-Sheet)。

主任务：明确赞成、反对或“未来在某条件下赞成”；聚焦一个判断标准，例如出生者的权益；给出一个假设例子并回应另一面。

### 对话任务

- **A・山田さん**：安全性と生まれる子どもの権利が十分に守られると仮定すれば、将来の選択肢として認めてもよいと思います。
- **B・陳さん**：私は反対です。周囲がその子に特定の生き方を期待して、本人の自由を狭めるかもしれないからです。
- **直接表达**：何を最も大切な判断基準にするかを示して、自分の立場を説明してください。
- **赞同补充**：AかBに賛成し、その立場を支える別の理由か具体例を加えてください。
- **委婉反对**：相手の主張を要約し、どの条件や考え方に同意できないかを具体的に述べてください。

提纲提示：賛否と条件 → 判断基準 → 生まれる人の立場からの例 → 相手への返答 → 結論。

表达工具：〜と仮定すれば／〜を前提に／〜とは限りません／〜だけでなく、〜も。

### 短口语示范与切分

**M3-A：未来条件赞成，回应反对意见**

1. 陳さんの心配はわかりますが、将来も絶対に認めるべきではないとは思いません。
2. 安全性と本人の権利が十分に守られると仮定すれば、選択肢として考えてもよいと思います。
3. 例えば、生まれた子が自分の進路を自由に選べることが必要です。
4. 技術が使えるかどうかだけでなく、その人がどう暮らせるかも考えたいです。

**M3-B：赞同反对，补充具体情境**

1. 私も陳さんの意見に賛成です。
2. 生まれる子どもが、誰かの代わりとして扱われることを心配しています。
3. 例えば、周囲が同じ仕事や生き方を求めたら、本人の希望が尊重されないかもしれません。
4. 一人の人として自由に生きられることを、何より大切にすべきだと思います。

练习焦点：M3-A第1片段含双重否定，先确认意思是“不认为将来都绝对不能允许”；初学者可改说「条件が整えば、将来は認めてもよいと思います」。第二次录音必须保留“条件是设想”的说明。

### 400—500字写作示范：反对（456字）

<!-- essay:opinion-human-cloning -->
私は、クローン技術で人を誕生させることには反対です。技術を使いたい人の希望だけでなく、生まれる子どもがどのように生きるかを、最も大切にすべきだと考えるからです。

私が特に心配しているのは、その子が誰かの代わりとして扱われることです。例えば、周囲の人が、ある人と同じ才能や生き方を期待し、同じ仕事を選ぶよう求めるかもしれません。しかし、生まれた子には、自分の興味や希望に合わせて人生を選ぶ自由があるはずです。周囲の期待を満たすことを、生まれた目的にしてはいけないと思います。

もちろん、安全性と権利を守る仕組みが整えば、認めてもよいという意見も理解できます。ただ、制度を作るだけで、家庭や社会の期待から本人を十分に守れるのか、私は疑問に思います。できる技術だから使う、という判断では不十分ではないでしょうか。

この議論では、研究用の細胞を作ることと、人を誕生させることを分けて考える必要があります。私は科学研究の全てに反対しているのではありません。生まれる人の自由を優先したいので、人を誕生させるための利用には反対です。
<!-- /essay -->

反向长文提纲：未来条件赞成 → 先说明安全与权益是假设 → 自主选择的价值 → 承认社会压力并给出保障条件 → 当前条件不满足时不实施。

追问：**「本人の権利が守られている」と判断するために、何が必要だと思いますか。**

专项自查：是否区分生殖性克隆和细胞研究；是否把条件当现实；是否尊重出生者的人格与权利；不能仅凭赞成或反对决定得分。

## 6. 题目四：电车内使用手机

### 题面与边界

**「電車の中では携帯電話を使うべきではない」という意見に、賛成ですか、反対ですか。**

场景：

> 授業で、電車内での携帯電話の使い方について話し合っています。通話、メッセージの確認、動画の視聴などのうち、どの使い方を念頭に置くかを明らかにして、意見を述べてください。

保留原题“使用手机”的广义表述，第一步先界定范围。“不赞成全面禁止”不等于“赞成大声通话”。本题讨论规则应如何设计，不陈述某铁路公司现行规定；不沿用图片作文中对其他乘客动机的猜测。

主任务：明确是否支持“所有使用都应避免”，至少比较两种使用方式，给出一个具体场景和自己的规则建议。若只讨论通话，要说明这是缩小范围后的意见，不能冒充已回答全部使用行为。

### 对话任务

- **A・鈴木さん**：私は電車の中では携帯電話を使わないほうがいいと思います。周りの人が静かに過ごせることを大切にしたいからです。
- **B・李さん**：私は全ての使用を控える必要はないと思います。音を出さずに乗り換えを調べることまで避けなくてもよいと思うからです。
- **直接表达**：使い方を二つ挙げ、どこまで控えるべきかを説明してください。
- **赞同补充**：AかBに賛成し、音以外の配慮や、別の具体的な場面を一つ加えてください。
- **委婉反对**：相手が重視している点を認めた上で、禁止や配慮の範囲について別の案を出してください。

提纲提示：対象の範囲 → 立場 → 理由 → 通話と無音操作の比較 → 提案。

表达工具：〜かどうかではなく／〜場合は／〜限り／全て〜必要はないと思います。

### 短口语示范与切分

**M4-A：赞同尽量不使用，补充周围注意**

1. 私も鈴木さんの意見に賛成です。
2. 電車の中では、できるだけ携帯電話を使わないほうがいいと思います。
3. 画面に集中すると、周りの様子に気づきにくくなることもあるからです。
4. 例えば、混んでいるときは、乗り降りする人に気を配ることが大切です。
5. 私は必要な確認を短く済ませ、あとは周囲に目を向けたいです。

**M4-B：反对全面禁止，提出按行为区分**

1. 鈴木さんの意見もわかりますが、全ての使用を控える必要はないと思います。
2. 音を出さずに使えば、周りへの影響を小さくできるからです。
3. 例えば、乗り換えを調べたり、家族に短いメッセージを送ったりする使い方があります。
4. 通話や音の出る動画は控え、使い方を分けて考えたほうがいいと思います。

练习焦点：M4-B第3片段的「〜たり、〜たりする」；再说时将例子换为另一种安静使用的用途，并加一句自己的边界。

### 400—500字写作示范：反对全面禁止（450字）

<!-- essay:opinion-phone-on-train -->
私は、電車の中で携帯電話を使うことを全て控えるべきだという意見には反対です。問題は携帯電話そのものではなく、どのように使い、周りにどのような影響を与えるかだと考えるからです。

例えば、音を出さずに乗り換えを調べたり、家族に到着時間を知らせたりする使い方は、移動中の生活に役立ちます。このような操作まで避ける必要はないと思います。一方、大きな声で通話したり、動画の音を外に出したりすると、静かに過ごしたい人の妨げになるかもしれません。そのため、使い方を区別することが大切です。

もちろん、音を出さなければ何をしてもよいというわけではありません。混んでいるときに画面だけを見ていれば、乗り降りする人の動きに気づきにくくなることもあります。操作をいったん止めて、周りを見る必要があるでしょう。

静かな車内を望む人の気持ちも理解できます。だからこそ、全面的に使用を控えるという一つの決まりよりも、音を出さない、通行を妨げないなど、具体的な配慮を共有したいです。私は、周囲の状況に合わせて使うことが大切だと思います。
<!-- /essay -->

反向长文提纲：原则上尽量不使用 → 注意力与共享空间 → 拥挤时的例子 → 承认必要的安静操作 → 明确“原则”与“紧急／必要例外”的关系。

追问：**音が出ていなければ、どのような使い方でも問題ないと思いますか。**

专项自查：是否回答原题的范围；是否把使用、通话、外放混为一谈；提出的是行为规则而非对他人性格的攻击。

## 7. 题目五：小城镇还是大都市

### 题面与边界

**住むなら、伝統的な小さな町と国際的な大都市のどちらを選びますか。**

场景：

> 将来住んでみたい場所について、友人と話しています。伝統的な小さな町と国際的な大都市を比べ、自分の生活で何を重視するかを説明してください。

可以根据工作、学习、交通、人际关系或生活节奏来选择。不预设“小镇都便宜安静”“大都市都便利冷漠”；具体条件用「私が考えている町では」「〜なら」说明。比较的是居住，不只谈短期旅游好不好玩。

主任务：选择一方，用两个比较标准说明理由；举一个日常生活场景；承认所选地点的一项不便并解释如何取舍。

### 对话任务

- **A・高橋さん**：私は伝統的な小さな町に住みたいです。地域の行事に参加しながら、同じ人たちと長く付き合いたいからです。
- **B・金さん**：私は国際的な大都市に住みたいです。さまざまな分野の人と出会い、新しいことを学ぶ機会を増やしたいからです。
- **直接表达**：どちらかを選び、自分が重視する条件を二つ示してください。
- **赞同补充**：AかBに賛成し、その場所で送りたい一日の具体例を加えてください。
- **委婉反对**：相手の希望を認めた上で、自分にはもう一方が合う理由を説明してください。

提纲提示：選択 → 比較基準二つ → 生活の例 → 不便な点への対応 → 自分との相性。

表达工具：私にとって／〜に比べて／〜という点では／〜ものの／〜としても。

### 短口语示范与切分

**M5-A：回应都市观点，选择小城镇**

1. 金さんの意見もわかりますが、私は伝統的な小さな町に住みたいです。
2. 新しい出会いの多さより、同じ人たちとの関係を大切にしたいからです。
3. 例えば、地域の行事を手伝いながら、少しずつ知り合いを増やしたいです。
4. 交通や買い物の条件は確かめる必要がありますが、自分に合う生活の速さを選びたいです。

**M5-B：赞同都市，补充学习机会的例子**

1. 私も金さんの意見に賛成です。
2. 私は学び続けられる環境を重視しているので、国際的な大都市を選びたいです。
3. 例えば、仕事のあとに語学の講座に通い、いろいろな背景を持つ人と話したいです。
4. 家賃や通勤時間も比べた上で、そうした活動に参加しやすい場所を探したいです。

练习焦点：M5-A第4片段的让步与结论、M5-B第4片段的「〜た上で」。第二次表达必须加入一条自己的生活条件，不能仅列抽象优缺点。

### 400—500字写作示范：选择大都市（464字）

<!-- essay:opinion-town-or-city -->
私は、住むなら国際的な大都市を選びたいです。今の私にとっては、落ち着いた景色よりも、学びや仕事の選択肢があることを重視したいからです。ただし、大都市ならどこでもよいという意味ではありません。

私が考えているのは、公共交通を使って仕事や講座に通いやすい場所です。例えば、仕事が終わったあとに日本語の講座に参加したり、休日に違う分野の人が集まるイベントに行ったりしたいです。いろいろな背景を持つ人と話すことで、自分が当たり前だと思っていた考えを見直す機会も得られると思います。

もちろん、伝統的な小さな町にも魅力があります。地域の行事に参加し、顔の見える関係を長く続ける生活にも憧れます。また、大都市では家賃や通勤時間が負担になることも考えられるので、住む前に具体的な条件を比べる必要があります。

それでも、今は新しいことを試し、自分の可能性を広げたい気持ちのほうが強いです。将来、暮らし方の希望が変われば、小さな町を選ぶかもしれません。私は場所の優劣を決めるのではなく、今の自分が大切にしたいことに合う場所として、大都市を選びたいです。
<!-- /essay -->

反向长文提纲：选择小城镇 → 重视持续关系与生活节奏 → 一天的具体安排 → 承认交通／机会限制并说明条件 → 适合自己而非适合所有人。

追问：**希望する仕事が小さな町にもあったら、選択は変わりますか。**

专项自查：是否真正比较居住生活；是否有自己的判断标准；是否把某个地点的条件概括成所有小镇或大都市的属性。

## 8. 页面上怎么组织这五题

进入「意见表达」先按推荐顺序展示五行题目，行内只有标题、主题、练习状态。首次学习推荐从「电车内使用手机」开始；不用展示教材照片文件名或内部ID。

进入题目后先选「说一段／写一篇」，再在题内切换「自己的意见／赞同并补充／委婉反对」。默认「说一段＋自己的意见」。对话练习显示A或B的发言，不同时铺开所有范文。

练习步骤：

1. **想一想**：读题、必要时界定范围，记录立场、理由、例子；最多显示五个功能提示。
2. **表达一次**：口语录音或保存作文；保存提示程度，不显示参考文本。
3. **回顾**：先自查是否切题，再展开参考范文。长文用四段功能标签，短文用意义片段。
4. **练顺口**：仅口语需要；选A/B短示范，逐句跟读或shadowing。无音频时保留文本学习，标明音频待补充。
5. **再表达**：隐藏范文，看自己的关键词重说；写作则保存修订稿。追问作为可选挑战。

长文的建议分配：立场约60字，理由与例子约170字，回应另一面约110字，总结约80字，总体以400—500字为目标；按内容调整，不要求每段字数刚好一致。编辑器统计包含标点、不含空白的字符数；段首空格与原稿纸占格方式另作说明，不能混称为正式考试计字标准。

结果页只优先显示「本次做到了什么」「下次改哪一点」与首次／再次版本。统一评价立场、理由、例子和衔接；每题额外使用上面的专项自查。对话题增加承接准确性；口语表现只有实际听过录音后才可评价。
