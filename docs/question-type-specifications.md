# 23题型内容、验证与呈现规格

2026-10-07。稳定 ID 与等级覆盖以 src/domain/questionContract.mjs 为机器索引；本文件是内容审查与实现规格，不代表每项新字段已实现。原分类证据见 docs/domain-model.md。正式分类与项目旧 kind 的精确映射见该文档。基础训练不参与正式卷覆盖统计。

## 共通契约

题目版本保存 taskConditions、明确目标位置、材料版本引用、稳定选项ID和答案；通用考试说明可由呈现层生成，但目标词、空位、主体、时限、检索条件均为内容。旧answerIndex始终0-based；数字answer只接受显式base，不推断。解析分为正确依据、每个干扰项理由、知识引用与技巧；不得仅复述答案。机器能检查结构和引用，不能证明自然度、唯一语义正确或音频与文字一致，必须保留人工审批。

作答前展示任务与允许公开的材料/选项，隐藏答案、解析、翻译、★正确排序和音频转录。即时练习提交后可展示正确依据与逐项排除；正式考试仅按容器授权在交卷后展示；回看可显示当时选项/答案快照。题型策略负责结构，容器负责授权、计时、导航、暂停和提交。

下面示例是小型内容示例，不是官方题或完整模拟题。长文/听力示例仍需充分材料与真实可播媒体才能成为验收fixture。知识关联可为零到多，区分目标/前置/对比；阅读技能与听力技能不能伪装成单词条。

## 漢字読み `vocabulary-kanji-reading`

任务：目标汉字词在句中读什么。

|维度|规格|
|---|---|
|payload必须保留|targetSpan、语境、假名选项|
|结构硬校验与内容审查|目标必须含汉字且定位唯一；专名多有效读音不得单一判错。引用、位置和枚举为硬校验；语义唯一性与自然度由审批检查。|
|解析模板|拆目标词读音→核对语境义项→辨长音促音清浊；每个选项说明其为何符合/不符合本题条件。|
|技巧|先确认词义再读，防止仅按单字音拼读|
|知识关联|单词义项、读音、同形异音|
|作答前|显示任务条件及获授权的材料；保持目标/空位标识；音频按题型控制预览。|
|作答后|按权限显示证据位置、正确选项与逐项解释；不以自评替代客观结果。|
|内容示例|彼は会議に【遅刻】した。→ちこく|

## 实施与验收边界

现有23种策略已提供别名、等级和基础答案归一化；完整payload结构校验、各型语义审批及各入口同一QuestionRenderer尚需后续阶段接入。docs/ui-question-experience是设计概念，不是已运行的跨端截图；fixtures不能只因覆盖23个ID就算完整内容验收。验收需包含多段长文、A/B双材料、表格多条件、★组句、篇章多空位、共享音频多问、隐藏转录、提交后解析、暂停恢复和窄屏溢出状态。
