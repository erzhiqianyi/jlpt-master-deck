Generated with the built-in ImageGen tool for the selected illustrated-handbook direction (option 1). Original source illustration files are retained as PNGs.

Shared art direction: horizontal 1536 × 640 composition; warm ivory background; dark sage outlines, soft greens and small apricot accents; original Japanese introductory-handbook illustration style; no embedded text, so explanatory captions stay accessible and localized in HTML.

- `learning-flow.png`: learner at laptop → friendly assistant → saved learning notebook.
- `connection-flow.png`: endpoint on laptop → authorization key and checklist → connected notebook.
- `practice-flow.png`: study notebook → assistant creates questions → learner checks answers and reviews progress.
- `media-flow.png`: learner with audio and passage → assistant analyzes material → saved question sheets.
